# Komentář k zákonu č. 585/2004 Sb., o branné povinnosti a jejím zajišťování (branný zákon)

Otevřený komentář k brannému zákonu — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; branná povinnost, záloha a aktivní záloha, krajská vojenská velitelství, vojenská činná služba mimo stav ohrožení i za něj, odvodní řízení, zdravotní způsobilost, vojenská evidence a ohlašovací povinnost, vojenská hodnost a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-2004-00585_2025-08-19`.
